# Виділення Картки Монети: Клік по Всьому Блоці

Дата: 2026-02-07

Коротко
- Вся картка монети стала клікабельною/виборною. Додано клавіатурну доступність (Space/Enter) та ARIA-атрибути.

Змінені файли
- `src/app/components/coins/coin-card.ts` (оновлено шаблон та логіку)
- `src/styles/components/coins.scss` (візуальний фідбек: hover, focus, selected)

Поведінка
- Клік по будь-якій ділянці картки перемикає стан вибору. Чекбокс відображає стан вибору; клік по чекбоксу не поширюється щоб уникнути подвійного спрацьовування.
- Картка має `role="button"`, `tabindex="0"` і обробляє `keydown.space` та `keydown.enter`.

Примітки для розробника
- Батьківський компонент оновлює сумарну інформацію про вибрані елементи та футер.

Відкат
- Повернути попередній шаблон, де вибір здійснювався лише через чекбокс та видалити клавіатурні обробники і ARIA-атрибути.
