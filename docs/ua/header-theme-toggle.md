# Перемикач Теми в Хедері

Дата: 2026-02-07

Коротко
- Додано кнопку перемикання теми в компонент `header`, яка напряму додає/видаляє клас `theme-dark` у `document.body`.

Змінені файли
- `src/app/components/header/header.ts` (додано логіку перемикання та сигнал `isDarkMode`)
- `src/styles/components/header.scss` (додано стилі для кнопки перемикання та перевизначення для теми)

Поведінка
- Під час першого завантаження хедер читає налаштування з `localStorage` (`enumerate-dark-mode`) або використовує `prefers-color-scheme`.
- Натискання кнопки перемикає темну тему, зберігає вибір і застосовує зміни негайно.

Примітки для розробника
- Сервіс теми не використовується; компонент безпосередньо змінює `document.body`.
- Файл темної теми повинен бути імпортований у `src/styles/styles.scss` для застосування стилів.

Відкат
- Видаліть кнопку та логіку `isDarkMode` з `header.ts`, і при потребі видаліть імпорт теми.
