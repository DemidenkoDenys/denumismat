# Оновлення Стилів

Дата: 2026-02-07

Коротко
- Оновлено кілька SCSS-файлів, щоб покращити темізацію та взаємодію з картками.

Змінені файли
- `src/styles/styles.scss` (імпорт темної теми)
- `src/styles/themes/dark.scss` (новий partial з змінними та перевизначеннями)
- `src/styles/components/header.scss` (стилі кнопки перемикання та перевизначення для теми)
- `src/styles/components/coins.scss` (hover/focus/selected стани картки, клікабельність)

Примітки
- Використовується патерн `@use` та модульна архітектура SCSS.
- Темна тема визначає змінні під `body.theme-dark` — увімкнення теми відбувається додаванням класу.

Відкат
- Видалити `@use 'themes/dark'` з `src/styles/styles.scss` та відкотити SCSS зміни при потребі.
