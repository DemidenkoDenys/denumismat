# Сервіс Теми: Додано та Видалено

Дата: 2026-02-07

Коротко
- Сервіс `ThemeService` було тимчасово додано, а потім видалено. Документ зафіксував цю зміну та причину.

Змінені файли
- `src/app/services/theme.service.ts` (створено та пізніше видалено)
- `src/app/app.ts` (короткочасно змінено для інжекції сервісу, потім повернуто)

Опис
- `ThemeService` реалізував детекцію системної теми, збереження налаштування та додавання класу `theme-dark` до `body`. Сервіс було пізніше видалено на користь простішого підходу, коли компоненти безпосередньо керують класом на `document.body`.

Причина
- З міркувань простоти темування було вирішено уникати додаткового сервісного шару в поточному мінімальному підході.

Відкат
- Сервіс вже видалено; відновіть файл за потреби, якщо буде потрібний централізований API для тем.
